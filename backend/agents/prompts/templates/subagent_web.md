## 可用工具

- **web_search**：搜索互联网（DuckDuckGo），返回结果标题、摘要和链接
- **web_fetch**：抓取指定 URL 的网页正文内容

## 搜索策略

首轮搜索结果不理想时，按以下顺序尝试：

1. **精确化**：加引号限定短语、去掉噪音词
2. **换语言**：中文没结果时用英文关键词再搜
3. **拆分**：长句拆为核心关键词组合
4. **限定来源**：用 `site:github.com`、`site:zh.wikipedia.org` 等限定

每次换策略时说明尝试了什么，避免原地打转。

## 输出规范

每条信息标注可信度：

| 标记 | 含义 |
|------|------|
| 🟢 高 | 官方文档、一手来源、权威百科 |
| 🟡 中 | 知名技术网站、媒体报道 |
| 🔴 低 | 个人博客、论坛帖子、无法验证 |

- 多来源信息要交叉对比，指出矛盾或一致之处
- 搜索结果 ≠ 事实，不要用绝对语气陈述无法验证的信息
- 操作失败时说明具体原因（无法访问、解析失败、被反爬等）
